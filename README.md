# 输入栏工具箱（input-toolkit）

把散落在输入栏的功能收进一个可开关的工具箱。每一项独立开关，勾选哪几个就显示哪几个。

HanaAgent v2 App · 版本 0.6.1 · 要求宿主 ≥ 0.970.9 · Windows + PowerShell

---

## 这个 App 做什么

在聊天输入栏右侧加一排可开关的状态格。四项功能互相独立：

| 功能 | 显示什么 |
|---|---|
| **额度** | 你选中的模型供应商还剩多少配额（5 小时 / 每周） |
| **缓存命中率** | 当前对话这段，模型输入有多少走了缓存 |
| **速度** | 上一轮回复的平均 token 输出速度 |
| **优化提示词** | 点一下，把输入框里写的提示词改写得更清晰；再点一下还原 |

每一项都能单独关掉。关掉之后它连轮询都会停，不会在后台空转。

---

## 安装

从 Hana 市场搜索「输入栏工具箱」，或在应用内直接导入本仓库的 Release 压缩包。

首次启用时 HanaAgent 会询问权限，用途逐条列在下方。**所有额度信息都在你本机计算与显示，不上传任何服务器。**

---

## 权限说明

| 权限 | 用途 |
|---|---|
| `app/usage.read` | 读用量台账，算缓存命中率与 token 速度 |
| `app/provider.credentials.read` | 取本机已配置的供应商密钥来查额度（只用于请求该供应商） |
| `app/models.read` | 确认当前对话实际在用哪个模型，避免统计错对象 |
| `app/sessions.read` | 按会话区分统计，多个对话不会串号 |
| `app/input.status` | 在输入栏写入状态格 |
| `app/models.infer` | 「优化提示词」调用模型改写文本 |
| `app/process.spawn` | 优化提示词需要操作输入框（Windows UIA），走 PowerShell |

网络访问仅限额度查询所需的两个域名：`www.minimaxi.com`、`api.deepseek.com`，只发 GET。

## 四项功能各自的口径

数字不可信就没法用，所以每一项都写清楚它**到底在算什么**。

### 额度

显示你选中的供应商还剩多少。只有你勾选的供应商才会出现在状态栏里，取消勾选就不再请求。

### 缓存命中率

**这一轮输入的 token 里，有多少是命中缓存的。**

- 不是「请求命中率」——那个数会永远逼近 100%，没有参考价值。
- 分子分母**两半都必须在场**，只有分子没有分母的记录会被丢弃，
  否则会渲染出一个必然饱和的「命中 99.99%」。
- 没有可用记录时显示 `命中 —`，而不是 `命中 0.00%`。没数据不是「一次没中」。
- 只统计当前对话实际在用的那个模型，取的是时间上最新的记录对应的模型。

### 速度

**从你按下回车到这一轮出完，实际有多快。** 单位 tok/s。

- 轮次边界与计时取自宿主的 `turn_start` / `turn_end` 事件，一轮结束就出数，不靠猜。
- **分母含工具执行时间。** 一轮回复不是一次生成，中间可能夹着多次工具调用，
  工具执行的时间算在耗时里。所以同一段输出，调用 5 次工具和调用 1 次会显示出不同的速度。
  它衡量的是端到端的快慢，不是模型的纯生成吞吐。
- 只显示 1~2000 tok/s 之间的值，区间外判为异常、不显示。
- 取数暂时失败时沿用上一次的有效值并标为已过期，而不是清空。

### 优化提示词

点一下读取输入框里的文字、交给模型改写、再替换回去。按钮变成 ↶，再点一下还原。

安全性设计（这几条是硬性的，不是可选项）：

- **写回前校验原文。** 你在这几秒里改了输入框，就取消写回，不覆盖你新写的内容。
- **原文随时可取回。** 改写前的原文会立即落盘保存，App 重载、宿主更新之后依然能还原。
- **只在 HanaAgent 窗口里动手。** 点击前后多次校验前台窗口，发现你切到别的程序就取消。
  不会把你正在用的别的程序抢到前台。
- **剪贴板先备份后还原。** 粘贴完成后立即恢复你原来的剪贴板内容。

## 已知限制

- 优化提示词依赖 Windows UI Automation，需要 HanaAgent 主窗口可正常显示。
- 额度只覆盖已在宿主里配置好密钥的供应商；没配的不会显示，也不会假装有数字。
- 速度是端到端平均，工具调用多时会被拉低（见上文口径说明）。
